# apka-ios

## Co to jest
Aplikacja sklepu na iPhone’a (SwiftUI).

## Jak uruchomić
Otwórz `Sklep.xcodeproj` i uruchom schemat `Sklep` na symulatorze.

## Struktura
- `Sklep/` kod aplikacji
- `SklepTests/` testy
