# sklep-api

## Co to jest
API sklepu: koszyk, zamówienia i płatności w trybie testowym.

## Jak uruchomić
`make dev` uruchamia API na porcie 8000. Szczegóły: docs/URUCHOMIENIE.md.

## Struktura
- `api/` punkty końcowe
- `core/` logika koszyka i zamówień
- `tests/` testy
